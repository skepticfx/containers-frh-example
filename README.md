# Containers Starter for Fedramp High Environment

## Getting Started

First, run:

```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

### Deploy
CLOUDFLARE_CONTAINER_REGISTRY=registry.fed.cloudflare.com CLOUDFLARE_COMPLIANCE_REGION=fedramp_high CLOUDFLARE_ACCOUNT_ID="id" npx wrangler deploy
